# 王者荣耀隐藏对局查询 API · 未授权号也能认

> 一句话：**对方关了战绩、甚至没授权营地，这一局的数据照样查得到。**

王者荣耀（Honor of Kings / 营地）的战报里，一旦对方关掉营地授权，
那一行就只剩一个占位标识（本文档里写作 `未授权游戏信息`）：

```
未授权游戏信息
```

`player_id` 空、`account_id` 空、昵称空、区服信息还在。

---

## 三种「隐藏」完全不是一回事

这是全网被问得最多、也答得最乱的问题。先把概念拆开：

| 状态 | 战报里的表现 | 历史列表 | 局内 10 人 | 能不能识别他 |
|---|---|---|---|---|
| **① 关了显示**（本人隐藏） | 字段齐全 | 空/不可见 | ✅ 齐全 | ✅ 完全可识别 |
| **② 从未授权营地**（脱敏号） | 昵称显示「未授权游戏信息」 | ❌ 永久为空 | ✅ 有行，但**匿名** | ✅ **可以**（结果标 ☆） |
| **③ 账号注销/封禁** | 无任何行 | ❌ | ❌ | ❌ 无法 |

⚠ 关键结论：**「隐藏战绩」和「未授权」是两件事**。

- 他只是在营地里关掉「战绩可见」→ **这一局的数据照样能查**
- 他从来没给营地授权过 → 历史列表是空的，**但这一局的数据同样能查**

## 快速开始

> ⚠ 示例域名是占位符，正式地址见页面底部。卡密请向作者获取。

### curl

```bash
curl -s "https://api.xiaohuamao.example/api/battle?target=营地号" \
  -H "Authorization: Bearer 你的卡密"
```

### Python

```python
import requests

r = requests.get(
    "https://api.xiaohuamao.example/api/battle",
    params={"target": "营地号"},
    headers={"Authorization": "Bearer 你的卡密"},
    timeout=20,
)
data = r.json()

for row in data["sides"]:
    mark = "☆匿名" if row["anonymized"] else row["role_name"]
    print(row["camp"], row["hero_name"], mark, row["total_win"])
```

### 返回结构（节选）

```json
{
  "match": "...",
  "mapName": "排位赛(三排)",
  "sides": [
    {
      "camp": "blue",
      "role_name": "未授权游戏信息",
      "anonymized": 1,
      "hero_name": "亚瑟",
      "total_win": 137,
      "matched_by": "heuristic",
      "certainty": "low"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `anonymized` | `1` = 脱敏行（未授权游戏信息） |
| `matched_by` | `uid` / `account_id` / `heuristic` / `zone` / `null`（认不出） |
| `certainty` | `hard`（硬证据）/ `suspected`（软证据，标 ☆） |

## 能查到什么

| 能力 | 说明 |
|---|---|
| 单局 10 人完整数据 | 输出、承伤、参团、经济、出装 |
| 同队 / 对手区分 | 谁跟他一队、谁在对面 |
| 好友双排 | 双方互加游戏好友的，逐局标出 |
| 固排统计 | 跨几十局聚合：谁反复跟他同队、同队几局、赢几次 |
| 未授权号识别 | 能认出来，结果标 ☆ |
| 实时对局 | 他正在打什么英雄、什么装备 |
| 开了隐身的号 | 隐身只挡住**好友列表**里的在线显示；查询不读在线状态，照样查 |

## 查不到什么

| 查不到 | 原因 |
|---|---|
| 未授权号的完整历史列表 | 拿不到，只能查已经发生过的单局 |
| 聊天记录 | 不存在这个东西 |
| 你的账号任何信息 | 只读游戏公开战报，不登录你的号 |
